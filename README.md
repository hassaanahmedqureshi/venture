# Venture

**Venture** is a custom WordPress business theme developed for the B&T Development technical assessment.

## Features
- Custom-coded theme (no pre-made themes or page builders used)
- Minimum 4 pages: Home, About, Services, Contact
- Fully responsive design for desktop and mobile
- Functional contact form
- Clean and professional layout
